# Galería de Fotos · Demo (Suite DC)

Demo de la Galería de Fotos de Digital Carmelo: panel del fotógrafo (páginas, álbumes, pedidos, precios, marca y cobro) y página pública para las familias.

Es una maqueta: no guarda datos ni sube fotos. Se publica en Netlify (galeria-escolar-dc).

## Cómo funciona el muestrario
- El fotógrafo sube la carpeta entera: la app achica cada foto y le pone la marca de agua en su compu, antes de subirla. Los originales no se suben.
- Cada álbum queda online 60 días (se puede extender 30), con aviso 7 días antes; al vencer se borra solo del servidor.
- Límite del plan base: 5.000 fotos online a la vez.
- "Descargar archivo" baja un `.dcmuestra` (fotos ya listas + datos del álbum). Con "Reactivar" vuelve a estar online 60 días, con la misma numeración y el mismo link.
- Los pedidos muestran el nombre del archivo original de cada foto para buscarlo en la compu.
